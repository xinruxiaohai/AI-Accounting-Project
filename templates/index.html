我的账本

版本读取中…

账本只存在本机 SQLite 里，不联网、不上传。想换台电脑接着记，就把数据导出去。

  • N 随时记一笔
  • Ctrl + K 搜索账单
  • 右键账单可编辑 / 删除 / 复制
CSV

导出全部账单

文件开头带 UTF-8 BOM，Excel / WPS 直接双击打开，中文不会变成乱码。 列包含日期、类型、分类、账户、转入账户、金额、手续费、公式与备注。 日期列已用 ="..." 包成文本，避免 Excel 显示成 ####；如果仍然看到井号，把日期列拖宽即可。

导出不影响账本数据，随时可以再导一次。

CSV / XLSX

导入账单

支持微信 / 支付宝导出的 CSV、Excel，自动识别 GBK / UTF-8 编码。 上传后先预览解析结果，重复项会高亮且默认不勾选，确认后才写进账本。

解析只读文件不写库；点【确认导入】才会联动账户余额。

帮助与快捷键
快捷键
  • N 快速记一笔
  • Ctrl + K 聚焦全局搜索
  • Ctrl + Enter 在 AI 快记 / 气泡输入里发送
  • Esc 关闭当前弹窗
  • ? 打开本帮助
功能速览
  • AI 快记：一句话记账、记借贷或加联系人；「帮同事代买咖啡 30」会自动挂到联系人名下待报销。
  • 悬浮球：点蓝色钢笔展开普通记账、AI 文本、AI 截图与帮助；点功能菜单不收起，鼠标移开悬浮球 3 秒后自动收回。
  • 账单流：点年 / 月 / 日表头可折叠，折叠状态会自动记住。
  • 资产页：小眼睛一键隐藏金额，点统计卡看明细，可上传自定义卡片背景图。
