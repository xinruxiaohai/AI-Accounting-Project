# 41 · v0.13.5 注册安全校验与登录页深度美化

## 需求背景

登录与注册共用一张卡片、一套 `submitGate()`。此前的做法是"提交前统一校验"，一旦给注册加上强密码规则，
**老账号（纯数字 `[默认口令已脱敏]`）会在登录 Tab 上被同一段代码拒掉** —— 这是本轮的死线：规则只能作用在注册视图。
同时登录卡片从 v0.12 起就是一块纯白板，和多层背景、深色主题都脱节，本版一并重做。

## 核心 Prompt（要点，非原文）

1. 滑块**未解锁**时不允许点「发送验证码」和「注册并进入」，按钮置灰或给出提示。
2. 「密码」下方新增「确认密码」输入框（仅注册视图可见）。
3. 注册强校验：不能是纯数字；**至少 8 位**，且**同时包含字母和数字**；不符合时输入框变红并提示。
4. 两次密码不一致时下方显示红字，并**阻止提交**。
5. **死线**：切到【登录】Tab 时严禁用上述强密码规则拦截提交，只要账号密码非空即可发登录请求，
   保证已有老账号（如 `[默认口令已脱敏]`）能正常登录。
6. 昵称 placeholder 改为「请输入您的昵称（选填）」。
7. UI：卡片改 Glassmorphism（`rgba(255,255,255,0.7)` + `backdrop-filter: blur(10px)`，深色自适应，柔和外阴影）；
   输入框圆角 8px 左右、聚焦发光过渡；滑块换现代样式、底色弱化；「注册并进入」主色调渐变 + 悬浮亮度；
   小屏不贴边、高度自适应。

## 方案简述

- **校验隔离**：`submitGate()` 只保留「账号密码非空」这条共同前置，注册额外跑 `validateRegisterFields()` + 滑块闸门；
  登录分支只 `clearFieldErrors()`。后端同步拆成 `_register_password_error()`（仅 `/api/auth/register` 使用）与
  `_password_strength_error()`（继续供改密 / 找回密码）。登录接口全程没有强度判断。
- **确认密码**：`#auth-confirm-password` 放在密码正下方，`.auth-confirm` 默认 `hidden`；切到登录时清空，
  避免切回注册带着上一次的残留值。
- **滑块闸门**：新增 `syncRegisterLock()` 作为 disabled 的唯一出口；发送验证码按钮的 60 秒倒计时不再直接写
  `button.disabled`，改为只维护 `data-counting` 标记，由闸门统一算最终状态。
- **文案前置**：密码 placeholder 随模式切换（登录「请输入密码」/ 注册「至少 8 位，需含字母和数字」），
  规则在输入前就可见，而不是提交后才红。
- **视觉**：卡片三层阴影（近描边 + 中扩散 + 远投影）、20px 圆角；输入框 10px 圆角 + 聚焦三层发光 + `transition`；
  滑块 46px 高、已滑部分渐变、圆钮渐变提亮；主按钮渐变蓝 + `brightness(1.09)` + 上移 1px；
  小屏 `max-height: calc(100vh - 28px)` + `overflow-y: auto`。

## 踩坑与结论

- **共用表单的隐性回归**：任何"提交前统一校验"的改动，都必须先问"这条规则属于哪个视图"。
  本次若直接把强度校验塞进 `submitGate()`，注册是合规了，登录会当场炸给所有老用户。
- **disabled 的多方争用**：倒计时、闸门、加载态都想写 `disabled`，谁最后写谁赢。必须收敛成单一函数，
  其余状态只写标记属性。
- **无头 Chrome 默认 `prefers-color-scheme: dark`**：断言浅色卡片前要显式 `data-theme="light"`，否则测的是深色。
- **CDP 清登录态别用 `addScriptToEvaluateOnNewDocument`**：它会在登录成功后的 reload 里再清一次，
  表现为"登录失败"。改用 `Storage.clearDataForOrigin` 只清一次。

## 自测

- 后端逻辑 11/11：8 位纯数字 / 纯字母 / 7 位均 400；`abc12345` 201 且响应不含 `password_hash`；
  老账号 `[默认口令已脱敏]` 登录 200；改密 `abc123` 仍 200（旧规则未误伤）；空密码登录 401 且报错不含强度文案。
- 真实 Chrome CDP 36/36：登录 Tab 提交按钮默认可用、`[默认口令已脱敏]` 能进应用；注册 Tab 确认密码可见、两按钮置灰、
  未解锁点发送实发 0 请求；纯数字与两次不一致各自红字且 0 注册请求；滑块解锁后恢复；解锁且合规后注册请求真实发出 1 次；
  深色卡片 alpha < 1、正文浅色可读；console 0 error。
