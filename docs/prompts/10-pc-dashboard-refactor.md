# 10 · PC 三栏看板重构（Prompt 快照）

## 一、这一步要解决什么

v0.06.1 的首页还是「一列到底」：统计卡、预算、账单、日历从上往下排，1440px 的屏幕左右各空一大片，账单表格还被挤得放不下金额列。

同时暴露了三个视觉问题：

1. 满屏实心黄/红按钮，重点全被抢走。
2. 日历热力图底色一深就把文字刷成白色，红绿白混在一起看不清。
3. 表格在窄窗口里把「金额」和「操作」挤出屏幕，必须横向滚动才能看一笔账。

这一步把首页改成 PC 后台常见的三栏布局，并把表格与热力图一起修好。

## 二、用户原始 Prompt（摘录）

> 首页太浪费宽屏了。改成三栏：中栏放本月支出大卡 + 预算环 + 近 7 天 + 全部账单，右栏放日历和当天明细。
> 顶栏搜索框要真正居中，左边标题、右边图标。侧栏加汉堡按钮可以折叠，刷新后记住选择。
> 表格最后一列不要再放编辑/删除按钮，改成点整行弹详情；按钮用描边幽灵样式，别再一片实心色。
> 日历热力图颜色最深也只到浅色，文字始终深色。

（Prompt 为要点摘录，非逐字。）

## 三、AI 给出的方案要点

### 布局

| 区域 | 实现 | 说明 |
| --- | --- | --- |
| 首页 | `.dash-grid`：`minmax(0, 1.55fr) minmax(320px, 1fr)` | 中栏主看板、右栏日历；≤1199px 自动变单列 |
| 顶栏 | `grid-template-columns: minmax(0,1fr) minmax(220px,460px) minmax(0,1fr)` | 搜索框在几何上真正居中，而不是靠 margin 猜 |
| 侧栏 | `.app.is-collapsed` + `--sidebar-collapsed-width: 76px` | 手动折叠状态写 `localStorage`；<1200px 自动收起，用户选过则以用户为准 |

### 主题与按钮

- 颜色全部收进 CSS 变量：`:root` 浅色、`[data-theme="dark"]` 深色两套，`body` 加 `transition`，切主题不闪。
- 删除/编辑等操作按钮改 `btn-outline-danger` / `btn-outline-warning`；主操作保留实心蓝。
- 图标按钮统一挂 `data-bs-toggle="tooltip"`，`delay: {show: 500, hide: 80}`，满足「悬停半秒才出现」。

### 表格与详情弹窗

- 删掉操作列：`records` 6 列、账户流水 5 列、当日明细 4 列，最后一列就是备注。
- 行变 `<tr data-id tabindex="0">`，整行点击（含键盘 Enter / 空格）打开 `#record-detail-modal`；详情里 Esc 关闭、Enter 编辑。
- `.records-table { min-width: 660px }` + `.table-responsive`；1439px 隐藏「账户」列、1199px 隐藏「备注」列 —— 金额永远可见。
- 左侧一列「时间」固定在窄屏也保留，因为它是用户找账的第一线索。

### 热力图

- `HEAT_MAX_ALPHA = 0.35` 封顶，最深的底色也只是淡色；删掉 `.is-deep` 的白字规则，结余固定深灰、收入绿、支出红。
- 废弃斜切纹理：纯色块 + 文字，信息密度更高。

## 四、结果

- 1440 / 1280 / 1024 / 768 四档宽度无横向溢出，金额列始终可见。
- 浅色、深色两套主题下对比度均达标；表格行点击、详情快捷键在 headless 里逐条断言通过。
