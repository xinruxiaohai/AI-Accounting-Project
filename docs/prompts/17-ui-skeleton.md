# 17 全站骨架 5:5 与「我的」页卡片统一（v0.09 Step1）

## 需求背景

v0.08.1 功能已闭环，但界面沿用早期 6:4 分块，侧栏偏宽、内容区被压缩；「我的」页通讯录占满下半屏，与「我的账本」卡片尺寸悬殊。用户要求先做宏观骨架、后做局部细节，Step1 只改样式与结构，不接复杂 JS。

## 核心 Prompt

> 全站分块左右比例 6:4 改 5:5；左侧深色侧边栏缩窄到只够放下文字；窗口变窄无法分块时降级单列堆叠；「我的」页把通讯录收缩成和「我的账本」一样的小卡片，新增回收站卡片，统一所有卡片的尺寸、边距与圆角。先只改 style.css 和 index.html，完成后极简汇报，肉眼确认后再接 Step2。

## AI 方案简述

用 CSS 变量 --sidebar-width 一处收窄侧栏；.dash-grid 的 1.5fr:1fr 统一改 1fr:1fr，1024px 以下的既有单列断点继续生效。我的页改用 .profile-grid 四卡两行，grid-auto-rows:1fr 强制等高，卡片统一 padding 22px，按钮用 margin-top:auto 贴底。通讯录主体移入 #contacts-modal，卡片只留说明与两个按钮，并删掉旧的展开/收起 JS，避免与 data-bs-toggle 抢事件；回收站先放占位卡，等 v0.09 回收站功能落地再接数据。

## 踩坑结论

- 侧栏不能按比例盲缩，要按最长导航文字反推宽度，176px 是「AI记账管家」品牌行与「回收站」等导航都不截断的下限。
- 卡片等高靠 grid-auto-rows:1fr，只写 height:100% 在内容不等高时仍会被撑开。
- 把 modal 塞进被 display:none 隐藏的 .page 里会导致弹窗永远打不开，必须放在页面 section 之外、同级 content 容器内。
