# 18 · 资产页重构、回收站与日历细节（v0.09.1）

## 需求背景

v0.09 骨架落地后，资产页仍是旧结构：顶部只有两栏数字，账户流水平铺一大串日期，看不出「这一天一共收了/支了多少」；「我的」页回收站只是占位卡，后端的 `records.deleted_at` 一直没启用；预算还在用 `window.prompt`，日历窗口一变宽格子宽度就参差不齐，深色模式下红绿底色发灰、「今天」的高亮圈偏暗。

## 核心 Prompt

一次性完成四件事：①侧栏必须真正锁在 176px 且文字不截断，日历强制 `repeat(7, minmax(0, 1fr))`；②资产页顶部做渐变净资产卡，下方拆总资产/总负债，再放借入、借出、待报销、已报销四张小卡，账户点开后按日期分组并给当日小计；③回收站接上软删除，弹窗里支持恢复与彻底删除；④预算改 Bootstrap 弹窗，日历今天改淡蓝、年月按钮圆角、图例居中、深色模式红绿提亮。顺序：修 Bug → 资产页 → 回收站 → 细节，全部自测后再汇报。

## AI 方案简述

后端把 `DELETE /api/records/<id>` 从硬删改成软删：写 `deleted_at` 的同时调用原有的逆向余额逻辑，恢复时再正向补回，彻底删除只允许删 `deleted_at` 非空的行。列表查询统一走 `_RECORD_SELECT` 并过滤已删数据，新增回收站列表、恢复、彻底删除三个接口。前端资产页把 `state.accounts` 与未结清借贷汇总成总资产/总负债/净资产，四张小卡里借入借出走 `/api/debts?status=unpaid`，待报销/已报销复用统计接口；账户流水按日期分组，每组先渲染一行 `colspan=5` 的日期与小计。预算弹窗写入 localStorage 后重绘预算进度与悬浮球。

## 踩坑结论

Bootstrap 在弹窗开/关动画进行中会直接忽略 `hide()`，保存按钮连点时弹窗会卡住，必须补一次延时 `hide()` 兜底（抽出 `hideModalSafe` 复用）。软删除如果只写 `deleted_at` 不回滚余额，回收站里的账会继续占着余额，必须在同一事务里做逆向记账。日历列宽错位的根因是 `fr` 没配 `minmax(0, …)`，内容一撑就溢出；侧栏「没缩窄」则是 `min-width` 与新宽度打架，必须把 width/min/max 一起锁死。
