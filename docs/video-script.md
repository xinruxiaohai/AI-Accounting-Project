# AI 记账管家 · 演示视频剧本

> 定位：3 分半产品演示，重点展示 v0.13.1 的分类隔离与配色、v0.13.2 的三项体验优化。
> 拍摄环境：本地 `http://127.0.0.1:5000`，1440×900，默认浅色主题，管理员账号。
> 要求：全程真实操作，不剪辑跳帧；每处改动用红框或箭头标注，方便观众跟上。

---

## 分镜表

### 0. 开场（0:00–0:20）

| 项 | 内容 |
|---|---|
| 画面 | 首页全屏；鼠标依次划过左栏五个导航，最后停在「账户与资产」 |
| 旁白 | 「这是一个本地部署的个人记账应用。没有构建步骤，起服务就能用。今天重点看三处刚做过的体验优化。」 |
| 要点 | 背景干净，关掉无关窗口；先把主题切回浅色 |

### 1. 账户与资产页（0:20–0:50）

| 项 | 内容 |
|---|---|
| 画面 | 进入资产页 → 净资产大数字从 0 滚到终值 → 四个统计卡依次滚动 → 账户余额逐个滚动 |
| 旁白 | 「进入资产页，总资产和各账户余额会从 0 滚到实际值。滚动过程中数字宽度是锁定的，不会左右抖。」 |
| 操作 | 切走再切回，滚动只在**首次进入**时播一次；之后只有数值变化才滚 |
| 标注 | 红框圈住「总净资产」，箭头指向借入/借出/待报销/已报销四张卡 |

### 2. 流水默认展开 + 可手动折叠（0:50–1:25）

| 项 | 内容 |
|---|---|
| 画面 | 右侧流水年/月/日三层分组全部展开 → 点「2026 年」表头收起 → 再点展开 → 刷新页面回到全展开 |
| 旁白 | 「进来默认是全展开的。需要的时候可以手动点收起，本次使用期间会保持；但刷新之后又回到全展开，不会记住上次的折叠状态——避免下次打开时找不到账单。」 |
| 操作 | 点表头收起 → 切到首页再切回来（仍收起）→ F5 刷新（回到全展开） |
| 标注 | 收起时用箭头标出「账单行数 10 → 0」 |

### 3. 页面切换动效（1:25–1:45）

| 项 | 内容 |
|---|---|
| 画面 | 依次点首页 / 资产 / 账单 / 图表 / 我的，每次目标页淡入并上滑 12px |
| 旁白 | 「页面切换加了 250 毫秒的淡入上滑，缓动是 ease-out。系统开了『减弱动态效果』的话会自动关掉，尊重系统设置。」 |
| 要点 | 建议用 0.5 倍速放一次，让观众看清位移；再放一遍正常速度 |

### 4. 全局语义色（1:45–2:15）

| 项 | 内容 |
|---|---|
| 画面 | 首页指标卡（支出红 / 收入绿 / 结余灰）→ 账单列表金额同色 → 切到图表页，三线同色 → 点月亮切深色，颜色跟着变且不刷新页面 |
| 旁白 | 「支出是红、收入是绿、结余和转账是灰。列表、指标卡、图表走的是同一套颜色令牌，改主题时全部同步——不用刷新页面。」 |
| 标注 | 切换主题时用箭头对比同一处颜色的前后取值 |

### 5. 分类隔离与停用合并（2:15–2:55）

| 项 | 内容 |
|---|---|
| 画面 | 打开分类管理 → 某个分类点「停用」→ 展开「已停用」管理区看到它 → 点「合并」选目标分类 → 合并完成 |
| 旁白 | 「分类是按用户隔离的，互相看不到。停用之后，新建账单时不会再出现它，但**历史账单仍然保留原来的分类**——编辑旧账单直接保存，分类不会被悄悄改掉。」 |
| 操作 | 关键镜头：打开一笔挂在已停用分类下的旧账单 → 什么都不改 → 保存 → 分类仍是原值 |
| 标注 | 红框圈住弹窗里的「已停用」角标 |

### 6. 收尾（2:55–3:30）

| 项 | 内容 |
|---|---|
| 画面 | 回到资产页，快速划过：动效、滚动、展开的流水、图表 |
| 旁白 | 「这版主要解决三类问题：进来就能看清全部账单、切换更顺滑、数字变化看得见。代码里所有金额都统一了千分位格式，也做了减弱动态效果的降级。」 |
| 字幕 | 项目路径、启动命令、文档索引 |

## 拍摄注意事项

1. **先清缓存**：静态资源带 `?v=0.14.0`，正式录之前确认加载的是新资源（DevTools → Network → 看 `script.js?v=0.14.0`）
2. **数据准备**：准备一笔金额较大（如 50,000.00）的账单验证大数字不溢出；准备一个已停用分类下的旧账单用于第 5 幕
3. **深色对比**：第 4 幕深色部分单独补一镜，展示对比度（标题 13.86:1、图标名 7.15:1）
4. **不要展示**：管理员密码、`.env` 内容、通知发布台后台
5. **屏幕录制**：建议 60fps，否则 250ms 的动效会糊；动效部分单独用 0.5 倍速重录
