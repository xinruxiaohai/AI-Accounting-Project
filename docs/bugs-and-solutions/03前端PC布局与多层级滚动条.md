前端沉浸式 PC 后台布局与多层级滚动条重构


问题现象
在引入三栏布局（左导航、中数据、右流水）后，页面出现严重的排版重叠（如卡片相互遮盖），且浏览器总滚动条与内部卡片的滚动条互相冲突，导致长列表直接把页面撑破。

根因分析
CSS 高度链断裂。父级容器缺乏 min-height: 0 约束，导致 Flex 子元素被内容无限撑大；不同模块间错误地使用了 position: absolute；PWA 独立窗口运行时，系统的原生控件遮挡了网页右上角的交互按钮。

解决方案与架构设计

全局视口锁定：锁定 html、body 高度为 100vh，禁用全局滚动。将滚动权限下放给各分栏容器（设置 overflow-y: auto）。

修复 Flex 塌陷：给所有包含列表的 Flex 容器补充 min-height: 0 属性，强制其根据父级计算高度，解决“内容溢出遮挡”的死结。

PWA 控件避让：配置 manifest.json 为 window-controls-overlay，并利用 CSS 的 env(titlebar-area-x) 等安全区环境变量，动态为顶部导航栏留出系统按钮的右侧边距。
