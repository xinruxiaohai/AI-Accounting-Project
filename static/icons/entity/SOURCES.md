- 京东 / 抖音 / 各银行行标无官方可用矢量，按规格用同色系通用图标 + 品牌主色近似，未硬造 logo。
- 分类图标与账户图标不同源属预期：分类内部统一 Twemoji，账户内部以品牌真 logo 优先。
